# Hitech Free

A simple, responsive static website built with HTML and CSS and hosted on Hugging Face Spaces.

## Features

- Clean and lightweight design
- Responsive layout for desktop and mobile devices
- No backend or database required
- Easy to customize
- Fast loading static files

## Project Files

- `index (1).html` — Main webpage
- `style.css` — Website styling
- `README.md` — Project and Hugging Face Space configuration

## Run Locally

1. Clone or download this repository.
2. Open `index (1).html` in any modern web browser.
3. To preview it with a local server, run:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Customize

Edit the HTML file to change the page content and edit `style.css` to change colors, spacing, fonts, and layout.

## Deployment

This project uses the Hugging Face Spaces **Static** SDK. Push the files to your Space and Hugging Face will serve the website automatically.

For more information, see the [Hugging Face Spaces documentation](https://huggingface.co/docs/hub/spaces).
